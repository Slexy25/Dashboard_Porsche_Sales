
 Porsche Sales Dashboard

![Dashboard Porsche](images/dashboard.png)

Dashboard interativo de análise de vendas de veículos Porsche entre 2021 e 2026.
  

📌 Sobre o Projeto

O Porsche Sales Dashboard é um projeto de visualização e análise de dados desenvolvido para facilitar o acompanhamento das vendas de veículos Porsche entre os anos de 2021 e 2026.

Com uma interface moderna, interativa e inspirada na identidade visual da Porsche, o dashboard transforma informações comerciais em gráficos, indicadores de desempenho (KPIs) e análises estratégicas.

O objetivo é proporcionar uma experiência intuitiva, permitindo explorar dados, identificar tendências de mercado e compreender o desempenho comercial de diferentes modelos da marca.

🎯 Objetivos

Facilitar a interpretação dos dados de vendas.

Analisar a evolução das vendas ao longo dos anos.

Identificar os modelos Porsche mais comercializados.

Comparar o desempenho de vendas entre cidades.

Identificar tendências e oportunidades de mercado.

Oferecer uma experiência de navegação moderna e responsiva.

🚀 Funcionalidades

📊 Indicadores de Desempenho (KPIs)

Visualização de informações relevantes para acompanhar os resultados comerciais, incluindo:

Volume total de veículos vendidos.

Faturamento total das vendas.

Preço médio dos veículos.

Modelos com maior volume de vendas.

Desempenho por cidade e período.

🔎 Filtros Interativos

O dashboard permite explorar os dados utilizando filtros personalizados:

Filtro

Descrição

Modelo Porsche

Seleção de modelos específicos

Model Year

Filtragem pelo ano do modelo

City

Análise de vendas por cidade

Sales Price

Filtragem por faixa de preço

📈 Visualização de Dados

O projeto apresenta gráficos interativos que permitem:

Acompanhar a evolução das vendas entre 2021 e 2026.

Comparar o desempenho comercial dos modelos.

Identificar os veículos mais populares em cada cidade.

Analisar a distribuição das vendas ao longo do tempo.

Visualizar tendências e padrões de consumo.

🚘 Catálogo Visual

Apresentação dos modelos Porsche com imagens ilustrativas, facilitando a identificação dos veículos e proporcionando uma experiência visual mais imersiva.

💡 Perguntas de Negócio

O dashboard foi desenvolvido para auxiliar na resolução de perguntas estratégicas, como:

Quais são os modelos Porsche mais vendidos em cada cidade?

Qual ano apresentou o maior volume de vendas?

Como as vendas evoluíram entre 2021 e 2026?

Quais modelos apresentam maior popularidade em determinadas regiões?

Como os preços dos veículos se relacionam com o desempenho comercial?

🎨 UI/UX Design

A interface foi concebida com foco em três pilares:

Minimalismo: organização visual que prioriza as informações mais relevantes.

Interatividade: filtros dinâmicos e gráficos que facilitam a exploração dos dados.

Responsividade: adaptação da interface para diferentes resoluções e tamanhos de tela.

A identidade visual foi inspirada na estética premium da Porsche, buscando transmitir sofisticação, tecnologia e desempenho.
